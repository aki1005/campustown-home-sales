College-Town Home Sales Explorer

Compare median prices, campus-area trends, and time on market across the dataset.

How to read these numbers: Q1 uses valid sale prices from $10,000 through $5,000,000, inclusive. Q2 uses all rows with no price filter. Q3 compares ranks calculated from all rows against ranks calculated from valid-price rows. Q4 uses valid sale prices. Q5 uses valid sale prices and only rows with both list_date and contract_date; days on market is contract_date minus list_date. Each listing is counted once using listing_id; repeated street addresses are not deduplicated.
